# Hyperboloid Stichting — Digital Rights Observatory

Independent research platform focused on freedom of speech, digital dignity, and institutional accountability.

## 🌐 Overview
Hyperboloid is a multilingual MPA (Multi-Page Application) designed for civic monitoring and research. It monitors censorship risks, supranational database integrity (Interpol, FATF, Egmont, PNR), and constitutional drift.

**Official Hubs:** Amsterdam · Berlin · Lyon · Riga  
**Contact:** research@hyperboloid.eu  
**LinkedIn:** [linkedin.com/company/hyperboloid-eu/](https://linkedin.com/company/hyperboloid-eu/)

## 🚀 Tech Stack
- **Frontend:** React + Vite + TypeScript
- **Styling:** Tailwind CSS + Framer Motion (for premium animations)
- **Icons:** Lucide React
- **I18n:** Custom JSON-based routing system supporting 7 languages:
  - English (EN)
  - Russian (RU)
  - Dutch (NL)
  - Spanish (ES)
  - French (FR)
  - German (DE)
  - Polish (PL)

## ✨ Key Features
- **Logo Identity:** Dynamic Blue-to-Burgundy periodic color transition with white glow.
- **Typewriter Subtitle:** Multilingual brand mission statement with animated typing effect.
- **SOS Incident Portal:** Real-time reporting for incidents involving international security organizations.
- **Whistleblower Portal:** Secure channel for reporting digital rights abuses.
- **Governance Transparency:** Clear organizational committee structure and public transparency reports.
- **Full SEO/SMM:** Automated meta-tags, OpenGraph, Twitter Cards, and sitemap generation for 42+ localized URLs.

## 🛠 Project Structure
- `src/components/`: Core UI components including Layout, SEOHead, and LanguageSwitcher.
- `src/pages/`: Page components (Home, Research, Publications, Roadmap, Governance, Contact).
- `i18n/site-content.json`: Centralized content repository for all languages.
- `openapi.yaml`: Public API specification for integration and reporting.
- `scripts/`: Build-time scripts for sitemap generation and SEO optimization.

## 📦 Getting Started
1. **Install dependencies:**
   ```bash
   npm install
   ```
2. **Start development server:**
   ```bash
   npm run dev
   ```
3. **Build for production:**
   ```bash
   npm run build
   ```
